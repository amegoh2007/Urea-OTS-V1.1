# Decided classes — `CLAUDE.md` section 5, rule 7

Moved from `CLAUDE.md` on 2026-11-11 (session 96, `CLAUDE.md` section 3a): the rule's own clauses, one
class a line, the wording unchanged. **Binding.** Once the process engineer has decided a class of V1
flaw, apply it without re-asking wherever a new unit shows it. A new mechanism still goes to the
process engineer, with both sides measured.

Never read it whole. Before a unit's physics is ported or changed, grep it for the mechanism and for
the equipment's kind: `grep -n -i "condenser\|vent" docs/decided-classes.md`. A decision number leads to
its full entry in `docs/decisions.md`. A class the process engineer decides later is appended here as
one line, with its decision number.
